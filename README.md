# Лабораторна робота №1 (Варіант 11 - Мобільний тариф)

## Опис
Програма обчислює місячну вартість мобільного зв'язку за використані хвилини, SMS та трафік.
Написана у функціональному стилі:
- `core.py` містить чисті функції (без мутацій та `print`).
- `app.py` відповідає за I/O (вивід на екран).
- Політики тарифікації та бонусів передаються через `typing.Callable`.

## Як запустити програму
```bash
python app.py
